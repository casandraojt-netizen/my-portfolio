### Project Overview
During my OJT at Callbox, I identified a need to streamline the End-of-Day (EOD) reporting process. This automation gathers task data and formats it into a clean Slack message.

### Tech Stack
* **Automation:** n8n
* **Platform:** Slack API
* **Data Source:** HubSpot / Google Sheets

### Key Features
* Automated triggers at 5:00 PM.
* Markdown formatting for readability.
* Direct integration with company Slack channels.
